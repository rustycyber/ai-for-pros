# CRISP Prompt Engineering Workshop

Welcome! This repository contains a simple Flask application with a bug.

## Workshop Objectives:
1. Run **Task 1: Vague Prompt** against your AI tool.
2. Run **Task 2: CRISP Spec Prompt** against your AI tool.
3. Compare the speed, accuracy, and format of both outputs.

Check `EXERCISE.md` for the prompt templates!
